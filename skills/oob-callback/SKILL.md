# 带外回连验证（OOB）

有些漏洞**在响应里看不到任何证据**，只能靠目标主动连回来确认。这个 skill 就是那条信道。

## 什么时候必须用

满足任一条件就走这个流程，不要靠猜：

| 场景 | 例子 |
|---|---|
| 参数被当作 URL / 域名 / IP 使用 | `?url=`、`?callback=`、`?image=`、`?webhook=`、`?file=` |
| XML 外部实体 | XXE 的 `SYSTEM "http://…"` |
| 命令执行没有回显 | 注入点能执行命令但响应为空 |
| 盲注只能靠时间/带外 | 盲 SQLi、SSTI 表达式 |
| 反序列化 / JNDI | Fastjson、Log4j 的 `ldap://`、`rmi://` |
| 服务端渲染外部资源 | 图片裁剪、PDF 生成、URL 预览、SSRF 打云元数据 |

## 四步动作

```
1. oob_new_session(label="<目标>-<漏洞类型>-<参数名>")
   → 拿到带 token 的回连载荷，含多种 IP 写法绕过变体

2. 把载荷注入目标参数（一次只改一个变量）

3. oob_wait(session_id, timeout=60)
   → 注入后立刻调，阻塞等回连；命中会返回来源 IP、请求全文、判定要点

4. 命中后 → oob_capability(session_id) 判级 → 写 finding；收尾 oob_close
```

**未命中时不要下"无漏洞"结论**，按序尝试：

1. `oob_payloads(session_id)` 换变体重试（十进制/十六进制/八进制 IP、IPv6 映射、`127.0.0.1@` userinfo 混淆、泛解析域名）
2. 调大 `timeout` 再来一次（队列、定时任务、异步回调可能几分钟后才连）
3. 仍无 → 才可写"带外未触发"，并注明已尝试的变体与时长

## 判级：它到底能干什么

`oob_capability` 返回等级。**盲 SSRF 和能干活的 SSRF 是两回事**，区别就在这个等级：

| 等级 | 含义 | 报告里的定性 |
|---|---|---|
| L1 | 单向回连，不跟重定向 | 盲 SSRF：能证明目标可出网、可被诱导发起请求 |
| L3 / L4 | 跟随重定向 | 可被诱导访问任意 http 下一跳，内网探测能力强于盲 SSRF |
| L5 | 跟重定向 + 处理 401 + 收 1MB | 渲染型客户端，具备把内网响应带回给攻击者的条件 |

判定驱动：注入 `cap_a1` 一条，后面几跳由目标自己的重定向跟随自动完成，无需人工多次注入。

## 红线（写报告前必读）

- **不得**把"未收到回连"写成"不存在漏洞"。目标可能不出网、被 WAF 拦、或只做 DNS 解析。
- **不得**把"未收到 `file://` 回连"写成"不能读取本地文件"。`file:///etc/passwd` 本来就不产生回连，收不到**既是**不支持**也是**支持但没回显。
  要确认读文件能力，必须满足其一：① 目标有回显并观察到内容透出 ② 目标是 Windows 用 `\\IP\share` 走 445 侧信道 ③ 已达 L5。
- **不得**拿回连来源 IP 直接当"目标出口 IP"结论——先跟目标自身出口比对，排除第三方误扫。
- 来源 IP 属内网段（10./172.16-31./192.168./169.254./100.64-127.）时，说明请求由**目标所在内网的主机代发**，这是很有价值的发现，要单独写。
- 载荷里已含 `169.254.169.254` 之类云元数据地址的判断，但**不要**真去拉取元数据内容以外的敏感接口。

## 载荷构成

`oob_new_session` 返回的每个变体 tag 不同，命中后看 path 第三段就知道**是哪条绕过生效**，写报告时能精确描述"用 X 写法绕过了 Y 校验"。

| 变体 | 用途 |
|---|---|
| `baseline` | 标准点分十进制，先试这个 |
| `decimal_ip` / `hex_ip` / `octal_ip` / `hex_dotted_ip` | 绕只匹配点分十进制的黑名单 |
| `ipv6_mapped` | 绕只校验 IPv4 的解析 |
| `no_scheme` / `double_slash` | 参数被拼进 URL 时用 |
| `userinfo_bypass` | `127.0.0.1@真实IP`，绕只匹配 host 里含 127.0.0.1 的弱校验 |
| `fragment_bypass` / `query_bypass` | 绕只做后缀匹配的校验 |
| `wildcard_nip_io` / `wildcard_sslip_io` | 泛解析域名，A 记录指向我们的机器 |
